# 离线影片

`journey.mp4` 使用用户提供的 `离线视频.mp4`，原文件直接复制，未重新压缩或改动音轨。
影片约 7 分 08 秒，2560×1440，59.94 fps，H.264 视频与 AAC 双声道音频。
网页入口为主页“开始航行（离线版）”。也可使用视频播放器直接打开本文件。
实时航行使用 public/audio/score.mp3；离线影片播放其自身已混入的音轨。
提交包只在本目录保存一份影片，一键运行服务提供相应 HTTP 路径映射及 Range 支持。
重新 npm run build 可生成包含影片的完整 dist/，供独立静态部署。

网页发布版为 journey-web.mp4（1080p/30fps，约32MB）。线上构建在没有本地原片时自动选择该文件；提交包继续使用原始影片。
