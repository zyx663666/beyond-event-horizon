# 离线播放影片

将最终 MP4 放在本目录，命名为 `journey.mp4`。

首页的“开始航行（离线版）”会进入独立的视频播放器，直接播放该文件。
该模式不创建 WebGL 渲染器，也不单独播放配乐，因此 MP4 应包含完整画面和声音。

建议使用 H.264 视频、AAC 音频的 MP4，以兼容桌面浏览器。
文件未添加时，页面会显示待就绪提示。

本地添加文件后，重新启动 `npm run dev`；发布或预览生产版本时，重新执行
`npm run build`。构建会自动包含此文件。使用完整本地站点文件夹时，播放无需联网。

若需修改文件名，编辑 `src/content/video.config.json` 中的 `file`。
