# 0.7 内容与视觉重构方案

390 秒，先规划再实现。沿用 0.6 已验证的 PG 自由落体、光锥与回声模型，将局部物理时间映射到新的剪辑时间。

0–34 秒：地球，系统启动，任务标题，依次引入档案时间、离家距离、光信号往返参照。
34–58 秒：太阳系导航重建，轨道缩放与光行时。天体和轨道不按统一比例。
58–82 秒：银河尺度地图。显示太阳位置，说明是地图，不是飞到银河外拍摄。
82–106 秒：恒星形成区与年轻星团，多波段重建，缓慢视差与体积尘云。
106–126 秒：超新星遗迹和脉冲星，慢化的周期脉冲可视化。
126–144 秒：遥远星系观测、档案跳转，切换至虚构目标 BH-A17 的本地中继。
144–334 秒：重新剪辑既有黑洞模型，加入曲光/多重像、频移、双钟、光锥和视界分析短暂停驻。291 秒穿越，304 秒最后回声，330 秒结束模型演示。
334–390 秒：明确艺术演绎；光锥/世界线到信号联系，再到星系网络与宇宙尺度，最后回望地球。

虚构任务参考：目标 BH-A17 距出发点 1200 ly，主要星际段档案平均推进约 0.2 ly/yr、历时约 6000 年；不声明现实已发现这一目标。银河图仅为尺度定位。遥测对象不声称逐一近距离飞越。离家距离与平直空间双向光行时 2D/c 同源，抵达目标后切换到局部 τ 与本地中继，不能混淆地球回信。

表层画面：NASA Blue Marble 地球贴图 + 程序云/大气；其他宇宙环境为原创实时程序重建。NASA 素材原始来源和署名写入资产记录。科学图解在影片中标为示意，不替代物理观测。

## 实施后的调整

原方案中的星云体积重建在视觉复查后改为有明确署名的 Webb 红外参考档案，以提高真实细节并避免给出虚假的三维结构。蟹状星云使用同样的档案语言，脉冲只在单独示意图中表现。新增延迟来光短注释；尾声先将象征光锥展开为世界线，再融入星系信号网络。最终结构与边界以 `reconstruction-0.7.md` 为准。
