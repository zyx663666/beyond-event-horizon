# Prototype 0.4 — Relativistic Observatory

本阶段从几何观测核心推进到背景光路驱动的相对论成像实验，保留 Three.js / TypeScript / WebGL2 / GLSL 与原有生命周期。按横屏 16:9 设计；未新增依赖。

## 已实现

- `lensing/geodesic.ts`：Schwarzschild 零测地线 RK4 积分、捕获锥、非线性角度采样和查表。
- `scripts/generate-lensing.mjs`：可重建的 1536 × 80 Float32 光路表，二进制约 480 KiB，附元数据与 SHA256。执行 `npm run generate:lensing` 后重新构建。
- `lensing/LensedSky.ts`：程序星空烘焙立方体环境图；每个屏幕像素按局部视线、观察半径和光路表查询天球。target/ultra 使用 2048 面分辨率 HDR 环境图，preview 512。默认仍为 target。
- 独立 GLSL 保留未折返的方位角，避免跨绕行圈数插值错误。CPU 仪表与 GPU 使用同一张表。
- S-01 是天球上同一个有限角大小参考源，参与真实映射而非复制两颗星；存在两支主要像，近轴时出现环状像。标注考虑阴影球和盘面近似遮挡。
- 弯曲光路 / 直线对照、天球标定网格、捕获半角、r/Rs、参考像标记。
- `camera/ApproachTrajectory.ts`：300 秒单向接近，半径 32 → 7.2 模型单位，C2 平滑关键帧与渐变镜头。最后外部停驻，时钟和信号继续。保留 `?journey=orbit` 历史航迹。
- `instruments/LensingPanel.ts`：独立成像仪表与航程读数，不把 UI 逻辑放进 Shader 或镜头。

## 方程、标度与适用范围

设 u=Rs/r，积分 u''=-u+1.5u²。局部静态观测系初值为 u'=u√(1-u)/tan(alpha)，alpha 从内向径向量起。临界冲量 b/Rs=3√3/2；捕获半角 asin[(3√3/2)√(1-1/r)/r]。

来源：[Oregon State — Bending of Light](https://sites.science.oregonstate.edu/coursewikis/GGR/book/content/bending.html)；[Observatoire de Paris — Black Holes](https://relativite.obspm.fr/blackholes/bholes.pdf)。

为使原有 1.24 阴影视觉尺度对应远场临界冲量，本版设 Rs=1.24/(3√3/2)≈0.4773 模型单位。时钟同步使用此 Rs，因此数值不与 0.3 的 Rs=1 直接可比。盘内缘 1.48 保持原样。模型单位未标定真实黑洞质量。

表域 8–96 Rs。默认航程约 67.05–15.09 Rs，在有效域内。临界角外 0.00002 rad 设置截断：不是无限精度的高阶像解。角度方向加密采样，半径轴使用 1/r。

## 明确的近似

1. 只有背景天球和 S-01 使用测地线传递。盘面、黑色阴影球、艺术亮边仍为原有几何渲染；阴影球略遮盖精确捕获边界。不是统一的盘面光线追踪，也不是已完成的物理光子环。
2. 静态、无自旋 Schwarzschild 模型；不含 Kerr、运动观测者像差、光行时、频率转移或偏振。
3. 星空由立方体纹理采样；参考源经有限角直径和导数抗锯齿处理，高倍放大与临界附近存在滤波、分辨率及截断误差。
4. B-01 仍是直线传播信号实验，未接入光路延迟；双钟为预设非自由落体轨迹上的度规积分。
5. 五分钟是外部接近镜头底座，不是五分钟完整叙事，不包含视界内解。

## 验证

- 20 项测试通过：既有 16 项回归加捕获锥 / 弱场极限、RK4 收敛 / LUT 抽样误差、五分钟航迹连续性与类时约束、光路产物校验和验证。
- 49 个独立半径与角度组合，距离临界角至少 0.001 rad；相对更细 RK4 步长的最大方位角查表误差约 0.001224 rad。这是抽样结果，不是整个域的严格误差上界。临界区不以此保证。
- TypeScript 与 Vite 生产构建通过；约 658 kB 主 JS 包保留体积提示，非构建错误。
- 横屏浏览器验证：环像帧、直线对照、曲光网格、300 秒终点、动态时钟与脉冲；未做竖屏校验。
- 未在 RTX4060 实机测定帧率；高品质配置保留，不能据开发预览推断最终设备性能。
