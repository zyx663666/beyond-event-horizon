# Prototype 0.5 — Unified Schwarzschild Observatory

版本目标：将星空、吸积盘、捕获边界、观测者局部状态和通信放入同一 Schwarzschild 外部模型。保持现有 App / RendererHost / FrameClock / Scene、Shader 管理与仪表结构；没有新增作品运行依赖，没有实现完整剧情。

## 实际实现

### 统一成像

`LensedSky` 现在负责完整相对论视窗，不再只绘制背景。旧的黑色阴影球、几何盘和艺术亮边退出主场景，历史模块保留。

每条相机视线经观测者局部 Lorentz 变换进入静态标架。在球对称场中光路位于中心平面，薄盘平面与轨道平面的交线给出候选穿越角。按顺序检查最多三次盘面穿越，首个落在 Rin–Rout 的交点决定可见不透明盘面；未击中盘面时再根据捕获锥和背景天球传递表成像。

因此背面上方弧像、下方盘像和更细的高阶盘像来自同一个盘面，未复制盘几何。图像中的 S-01 蓝色大环仍为远方参考星近轴环像，不能与盘面的临界子像混淆。

### 盘面频移与发射时间

盘面使用 Schwarzschild 稳定圆轨道速度。Rs≈0.47728 u，Rin=1.48 u≈3.10 Rs，处于 ISCO 外；配置拒绝 Rin<3 Rs。盘内缘静态标架轨速约 0.488 c。

- 轨道角频率：Omega = c sqrt[Rs/(2 r³)]。
- 局部轨速：beta = sqrt[Rs/(2(r-Rs))]。
- 观测者局部速度：beta_r = v_r/(c f)，beta_perp = v_perp/(c sqrt(f))，f=1-Rs/r。
- 发射／接收频比：g = sqrt(f_emit/f_obs) D_obs / [gamma_emit(1-beta_emit·n_photon)]，其中 D_obs=gamma_obs(1+beta_obs·sight_static)。
- 发射方向的切向分量由守恒冲量确定，减少径向插值梯度对频移的污染。
- 程序盘纹使用 t_emit=t_observer-Delta_t；同一盘面不同像可以呈现不同发射时刻。
- 亮度以 g⁴ 的总辐射转移驱动，色温按 T_obs=g T_emit 映射到近似黑体 RGB。该显示并非精确的可见光带积分。

曝光、Bloom、温度标度（默认 6500 K）和纹理仍是作品参数。频移对照仅将辐射 g 置为 1，像差和光路仍保留；直线对照关闭空间弯曲，但保留临界捕获锥作为比较基准，它是混合诊断视图。

### 统一时间与通信

`SchwarzschildSpacetime` 同时供视窗、观测者本地钟和 `SchwarzschildPropagation` 使用。光速 c=4 u/s 为模型单位，与真实黑洞质量尚未标定。

`connection.ts` 通过守恒冲量与有限端点夹角求解主零测地线。径向单调分支与存在转向点的分支分别计算，Gauss-Legendre 积分使用 r=r_peri+x² 去除转向端点奇性。角度积分为 b/[r² sqrt(1-b² f/r²)]，坐标时间积分为 1/[c f sqrt(1-b² f/r²)]。

脉冲去程使用发射位置到固定 B-01 的主光路；回程解 t-t_reply=T(B-01, observer(t))，在每帧内线性插值移动接收者并求交。本地钟保留梯形积分。信标 0.4 s 应答等待解释为信标本地钟间隔，转换为坐标等待。RX 时记录该接收位置、帧内速度与频比，之后读数冻结为接收确认。此前显示的是模型预测。

信标标注采用通信光路的入射方向与观测者像差，不再直接投影 Euclidean 端点。它是无线导航注释，未渲染成发光物体。

## 方程和工程资产

背景表仍采用 0.4 的 u''=-u+1.5u²，u=Rs/r。新增轨道表覆盖捕获边界两侧，存储 u(phi) 和坐标传播时间，离线自适应 RK4 生成。

| 资产 | 格式与域 |
|---|---|
| 天球传递表 | 1536×80 Float32，逃逸方位角 |
| 盘面轨道表 | 1024×320×48 RG16F，局部发射角 × 轨道方位角 × 1/r_obs |
| 观测者半径 | 8–96 Rs；当前航程约 67.05 → 15.09 Rs |
| 轨道方位角 | 0–3 pi；最多三次盘面穿越 |
| 时间通道 | c Delta_t/Rs - [r_obs/Rs + ln(r_obs/Rs-1)]，采样后恢复公共延迟 |
| 传输／GPU 数据 | gzip 约 14.9 MiB，解压 RG16F 60 MiB |

半径／角度／层均手动插值，不要求浮点线性过滤扩展。星空 HDR 立方体 target/ultra 仍为每面 2048，未削减最终质量；去除不需要的星空烘焙深度缓冲。表生成脚本与 SHA256 可复现。

源码层次：`geodesic.ts` 天球、`orbit.ts` 盘面路径、`connection.ts` 通信边界问题、`SchwarzschildSpacetime.ts` 局部观测状态、`SchwarzschildPropagation.ts` 通信模型；GLSL 统一着色，DOM 仪表独立。

## 科学边界与当前限制

1. Schwarzschild 无自旋模型，静态外部坐标；目前不能跨视界。观测平台是预设加速航迹，未求解自由落体。
2. 吸积盘是零厚度、不透明、固定内外缘薄盘，没有 GRMHD、体辐射传输、吸收、偏振、盘自重或 Kerr 拖曳。
3. 径向辐射包络为带零内缘通量的简化薄盘表达，未实现完整 Novikov-Thorne 模型；噪声、密度结构、有效温度归一化、Bloom 和摄影曝光属于工程／艺术表达。
4. 临界区图像受查表、半精度、屏幕采样与三次穿越截断限制；可见细环是有限高阶盘像，不表示已解析无限阶完整光子环。
5. RGB 黑体近似与 g⁴ 亮度代理不能替代完整谱辐射计算；背景星谱保持程序 RGB，仅亮度随接收频率因子变化。
6. 通信只取主路径，不包含多路径回波、信号强度与带宽。模型假设盘面对通信波段透明；如果需真实无线传播，必须加入等离子体与吸收模型。
7. 动态接收者在帧内线性插值，实验钟按帧积分；静态光路数值求解是准静态端点问题，没有旋转／动态度规。
8. 轨道资产约 15 MiB，HDR 环境图也有显著显存成本。加载先显示状态，编译完成后启动航程，不将预热耗时计入实验钟。
