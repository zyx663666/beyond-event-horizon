# 电影化观测版 — 2026-10-01

基于 Prototype 0.5 的外部航程新增电影模式，入口 `?mode=film&quality=target&debug=0`。仍是实时 WebGL 预览，未导出视频、未配乐。

- 固定 16:9 画幅，其他横屏窗口以黑边容纳；画面重新居中，取消为底部实验面板预留的偏移。
- 四章：寻光、曲光、双钟、临近。五分钟中六处英文主句与中文副句，按航程时间淡入淡出，共 59 秒字幕窗口，约占 20%。
- 仪表缩减为半径、双钟和通信状态。35 秒开始自动发送，之后至少间隔 48 秒，前一回波未到达时不重发；280 秒后不再发新脉冲。
- TX、RX、往返时间来自现有 SignalExperiment；不提前展示远端发生的事件。定格画面明确标为 STILL，冻结通信和时钟。
- 电影模式与观测模式可通过右上角切换；切换重新加载并从头开始。现有调试与观测功能保留。
- 当前结束于约 15.09 Rs 的外部停驻，末句为“此刻，仍有一条通向外界的光路”。没有将视界、自由落体、失联写成已实现现象。

## 验证

`npm test`：25 项既有回归测试通过。`npm run build`：通过，保留已有大包提示。

`node scripts/verify-film.cjs`：检查六个时间点、1600×900 和 1280×720、1600×1000 下的 16:9 黑边构图、自动 TX/RX、切回观测模式。输出 `artifacts/film-checks.json` 和 `artifacts/film-*.png`。

## 后续物理阶段

视界穿越需要规则坐标、自由落体观测者标架，以及支持该区域的光路和通信模型；当前查表不可直接外推。应先数值验证，再用相应数据驱动“出站信号无法逃逸”的叙事。视界处不制造实体屏障或爆炸，不将因果描述为失效。音轨与最终影片剪辑尚未完成。
