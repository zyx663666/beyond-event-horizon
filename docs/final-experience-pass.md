# Final Experience / UI, Credits & Pages Pass

本轮把默认入口改为实时深空观测台，完成科学锚点注释、任务仪器栏、航程时间线、可编辑片尾，并加入独立的新片头与静态发布结构。原有地球到黑洞的 6:30 内容、吞噬事件、穿越与艺术尾声保留。全片含包装为 **7:42**。

## 默认体验与仪器

Observatory 以正在运行的 Schwarzschild 成像场景为背景，黑洞置于画面右侧；左侧依次呈现任务身份、作品标题和两个入口，底部是观测钟、半径与模型状态。它是定点观测者，盘面和成像持续更新。START JOURNEY 进入导演航程；FREE OBSERVATION 在同一观测台开放拖动/方向键视角、光学变焦、Home 回正。后续路线选择与驾驶未在本轮扩张。

Film HUD 左上承担章节与任务，右上承担观测对象与模型边界。底部保留五个仪器槽：前半程为航程时率、任务纪年、离家距离/光行时、目标距离、中继；黑洞主场切为固有时、面积半径、视界坐标差、外发频比、中继。避免重复显示同一信息。

Mission Timeline 使用 Earth、Solar、Deep Space、Binary、Pulsar、Black Hole、Horizon、Last Echo、Archive 九个稀疏节点。保留拖动、暂停、重播、章节选择与键盘能力，节点系统仍可接入未来交互。科学观察速度曲线是连续且单调的时间重映射；前半程解释中心约 0.55×，黑洞段按观测窗口平滑降速，画面与物理钟不再为了讲解硬冻结。用户主动暂停依然可用。

## Anchor Annotation 与动效

电影模式原来的左侧大解释框已替换为目标锚点 → 扫描环/锁定点 → 细引导线绘制 → 右侧标题、中英短解释、简图与观察时率。地球、太阳、脉冲星使用场景相机投影；黑洞来光/光锥等标明 INSTRUMENT REFERENCE，作为探测器示意而非伪造天体实体位置。旧实验室界面通过 mode=lab 保留。

标题采用位置、字号、字距和透明度组合；坐标使用逐位扫描；科学注释逐层展开；仪器数字按本地和远端刷新节奏更新；警告低频呼吸，哲学句子简单淡入/淡出。黑洞附近的远端读数刷新变慢，并显示 REMOTE NOW UNCONFIRMED；最后 ACK 明确是跨越前发出的入射回声。NO OUTBOUND PATH 不会因收到旧回声而恢复为正常通信。

声音默认关闭，用户启用后才创建/恢复 AudioContext。接口包含 boot、lock、annotation、received、relay、slowdown、resume、horizon、no-reply 等克制设备提示。背景合成为临时声音，最终配乐尚未制作。

## 边界与待精修

Schwarzschild、自由落体、光路和因果结构是理想化科学模型；薄盘辐射、受控吞噬流和视差宇宙是工程近似，不是完整流体与多体模拟。6000 年/1200 光年航程为压缩档案，不代表超光速。科学模型结束后的部分明确为艺术表达，不宣称知道奇点内部。

近地极近景的云纹理与双层大气仍可进一步精修；部分粒子远景仍能看出工程近似。作者信息与最终哲学句暂保留占位，最终音乐/音效、视频导出与竞赛包装尚未制作。RTX 4060 需验证 2K/4K 帧率、体积云负载、着色器首编译与网络冷启动，当前 GTX 760 不能替代这些结果。
