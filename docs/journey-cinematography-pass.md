# Prototype 0.7 — Journey Cinematography Pass

副标题：从地球到黑洞的连续宇宙航程重构。完成日期：2026-10-02。

本轮将影片前 144 秒改为共享三维舞台上的连续航程。总长仍为 390 秒（6:30）；黑洞主场、4:51 视界穿越、5:04 最后回声和 5:34 艺术尾声的结构保留。UI 沿用已有稀疏中英仪器系统，没有扩写尾声或开发自由驾驶。

预览：[Film Mode · target](http://127.0.0.1:5176/?mode=film&quality=target&debug=0&pass=journey)。固定 16:9，可暂停、重播、拖动进度；临时声音仍可选。

## 哪些场景替代了静态前奏

- 原平面地球视图改为实时球面地球：自转、分离云层、大气辉光和移动相机共同产生空间变化。NASA Blue Marble 只作为球面表面纹理。
- 太阳系和银河平面示意改为同一三维空间内的行星、太阳、轨道与银河粒子分布。轨道距离、天体尺寸和显现时机经过电影化压缩。
- Webb 星云与蟹状星云图片不再进入主航程；形成区和遗迹改为具有空间深度的粒子、暗尘、发光恒星、喷流与丝状结构。
- 原目标前的平面深空图段改为脉冲星离场、相机转向和黑洞渐近获取。前奏不再使用章节暗场快门隐藏换图。

相机位置、注视点和视角以绝对电影时间采样。分段五次缓动在观察点平滑减速和起步，航路星点与拉丝跟随推进节奏；所有前奏对象在共享世界内，不在章节边界交换背景图。普通星空和黑洞来光使用同一星空环境。2:24 的接入还匹配了相机位置、方向和径向速度，避免主场开始时突然跳位。

这是一条视觉连续的压缩航程，不是以真实天文距离飞行的导航模拟。仪器中的任务年代、距离和信号延迟沿用已有任务档案逻辑；三维舞台长度不能直接换算成这些读数。银河主要建立方向和尺度，BH-A17 是虚构目标，不宣称位于银河中心。

## 三个动态观测事件与黑洞吞噬

恒星形成区通过三维尘云和年轻恒星的相对移动呈现进入、停留和离开；双星本身持续绕行；脉冲星通过旋转束扫过空间，而非让整颗星周期性熄灭。这些事件有简短 FIELD NOTE 和航程恢复提示，未增加长篇旁白。

潮汐撕裂采用嵌入既有黑洞成像的动态薄发光源：恒星接近后被拉长，形成向内缠绕的流带和向外延展的尾迹，随后盘面局部发光增强。光源在反向光路的平面命中处求值，参与既有的遮挡、捕获和弯曲来光；按光路延迟采样源的较早状态。恒星和尾迹亮度经过收敛，黑洞阴影与盘面仍是视觉中心。

该事件持续演化并逐渐退去，不是切入独立素材。源形状和物质运动为程序化示意，不是恒星流体或磁流体数值模拟；片中的压缩时长也不是对真实撕裂时间的预测。

## 科学模型、工程近似与艺术边界

| 层次 | 本轮采用的方式与限制 |
|---|---|
| 科学模型 | 黑洞仍采用既有 Schwarzschild 非旋转模型、光线积分、薄盘成像、双钟和通信因果结构。没有增加可见视界墙、爆炸或传送门。 |
| 工程近似 | 相机尺度压缩、普通星空到引力成像的渐进混合、双星圆轨道与减速脉冲束、程序星表、有限光路预算。前奏不做全域相对论传播。 |
| 2.5D 辅助 | 尘云采用置于三维空间的软粒子面片；恒星光晕为发光面片；潮汐物质源仍位于薄平面。它们便于实时预览，不等同于完整体积辐射或流体模拟。 |
| 纹理／图片 | 主线只请求 NASA 地球表面纹理。Webb 图片留在素材目录与历史署名中，不再作为动态旅程场景。 |
| 艺术表达 | 尘云形态、色彩、航程压缩、撕裂源动力学与既有未知区域尾声。尾声仍明确标记艺术演绎，不声称展示奇点内部真实结构。 |

科学概念参考：[NASA：恒星撕裂与物质流](https://www.nasa.gov/universe/nasas-swift-mission-maps-a-stars-death-spiral-into-a-black-hole/)、[NASA：TESS 潮汐撕裂观测](https://www.nasa.gov/universe/nasas-tess-mission-spots-its-1st-star-shredding-black-hole/)、[NASA：脉冲星旋转辐射束](https://science.nasa.gov/mission/hubble/science/science-behind-the-discoveries/hubble-pulsars/)。地球素材及历史档案署名见 `public/cosmos/CREDITS.md`。

## 后续交互接口

`src/film/journey/route.ts` 提供 Earth、Solar、Galactic、三个观测目标、Black Hole Target、Black Hole Core 和 Horizon 节点，支持 seek、navigate、hold、replay 和时间驱动 cue。FilmApp 已实际使用该控制器。

窗口事件 `journey:navigate`（detail: node、play）、`journey:hold`、`journey:event`（detail: id='tidal-disruption'、enabled）可驱动已有预览。根节点发出 `journey:cue`。目前只预留节点与事件控制，不提供完整自由驾驶或分支任务界面。

## 验证与交付限制

- 生产构建通过；34 项测试通过，包括镜头有限性与连续性、黑洞接入速度匹配、节点停留／重播和事件触发。
- 浏览器检查 26 个时间点，无运行或着色器错误。地球、星云、双星、脉冲星的间隔取样均存在画面变化；潮汐事件开关对照显示实际画面响应。
- 实时连续播放覆盖 0–185 秒；另检验穿越至最后回声的实际播放、片尾结束、16:9 布局和 WebGL 上下文恢复。没有把抽样检查描述为整部 390 秒再次完整实播。
- 独立精确检查在 143.990 与 144.010 秒确认不同时间被真正采样，镜头跨接入点连续。此前滑块 0.1 秒取整造成的零像素差不作为衔接证据。
- 资源请求记录中仅有地球图片，未加载 Webb 星云图片。报告位于 `artifacts/journey-cinematography-checks.json` 和 `artifacts/journey-final-checks.json`；画面取样位于 `artifacts/journey-*.png`。
- GTX760／ANGLE 的 1280×720 开发环境中连续播放样本约 75–102 FPS；这不代表 RTX4060 最终性能，也不代表所有分辨率。RTX4060 实机和最终输出分辨率仍待验证。

当前最大短板是尘云与遗迹的材质质感：体积层次已建立，但软粒子密度、内部照明和丝状细节仍偏程序化。潮汐物质流也仍是薄平面示意，需要进一步精修厚度、形态与亮度节奏。地球云层／大气、轨道尺度显现和各段减速时机可继续微调。最终音乐、视频导出、竞赛包装与 RTX4060 验证尚未完成，本轮没有扩展这些工作。
