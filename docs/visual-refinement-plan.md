# Visual Refinement & Cosmic Events Pass

保持 390 秒剪辑、UI、穿越与尾声逻辑。精修实时地球、连续运镜、关键星云体积与背景距离层级；扩展黑洞薄发光源事件，保留既有 Schwarzschild 光路。

计划：
- 地球自转由 0.007 调至约 0.018 rad/s，独立云层、柔化昼夜过渡和海面反射，大气双层辉光。
- 相机在转运节点保留速度，仅关键观测点停驻；加入缓慢非周期漂移。
- 恒星形成区和遗迹增加有界 3D 密度场体积积分，软粒子只补细节；降低线框感。
- 背景加入三维疏密星场、星团、少量远方程序星系及暗尘；远方星系进入统一环境图，继续参与黑洞透镜。
- 恒星撕裂作为重点镜头：完整星体、逐渐伸展、双向剥离流、局部热点响应；气体捕获短镜头，残骸轨道衰减短镜头。多路径像来自光路求解，不复制屏幕图像。
- 来源形状、气体运动和轨道衰减为工程示意；不声称做了恒星／气体流体力学、物质测地线或能量守恒模拟。已知源和空间场景均确定性按时间采样。

检查：构建、已有科学／镜头测试，关键镜头与事件开关对照、短段真实播放、视界与回声回归、16:9、GPU错误与上下文恢复。GTX760 仅开发验证，RTX4060 质量和最终分辨率需另测。
