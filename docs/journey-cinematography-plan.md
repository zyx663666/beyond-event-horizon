# Prototype 0.7 — Journey Cinematography Pass

本轮主任务：将 0–144 秒的平面图像前奏改为连续三维航程，不延长 390 秒，不改黑洞内核与尾声结构。

镜头结构：0–32 近地地平线拉远；32–57 连续退出至压缩太阳系；57–76 太阳缩入星场并转向；76–94 穿行恒星形成区；94–110 接近、绕观测与离开双星；110–126 经过脉冲星遗迹；118–144 引力目标由转向与渐近成像显露；144 秒衔接既有 Schwarzschild 旅程。

实现：真实三维地球/月球/行星/太阳与轨道；三维银河粒子分布、航路星场；粒子体积尘云辅助、双星实时轨道、旋转脉冲束与遗迹丝状结构。仅地球保留 NASA 表面纹理；Webb 档案不再作为主场景。前奏取消暗场快门。

黑洞吞噬：在既有反向光路的盘面交点上加入程序化潮汐伸展和物质流发光源，耦合盘面增亮。该事件是薄发光源与示意动力学，不声称做了恒星流体模拟；光路仍采用现有 Schwarzschild 模型。需实测画面后调整位置、亮度和时刻。

未来接口：独立主线节点/镜头采样、节点跳转与停留/重播、时间驱动事件提示。电影模式直接使用控制器，不开发自由驾驶 UI。

验收：三维镜头连续性、至少三个动态事件、黑洞显露衔接、吞噬事件的画面变化、已有穿越/最后回声不变、构建与针对性浏览器检查，保留预览。
